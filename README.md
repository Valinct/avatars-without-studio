# Roblox Avatars
I let **Meshy.ai** build AI Avatars for **Roblox** with AI Generated images from *Duck.ai*, Here's where it all broke! :(.

I ought to build a roblox avatar using AI, but I had limitations, Roblox Studio didn't work on my device! I still gave it a try! I did not spend a single penny. So, if you are a Free Tier person as well, you might get some insights. I used Meshy.ai's official guide to learn this AI.

## The Build
1. Brainstorming
2. From Concept to Image ( Duck.ai )
3. From Image to Model <- Where it actually broke!

I began with brainstorming, thought of few concepts linked and analysed multiple roblox avatars and used *duck.ai* to create the concept art. 

**The First Pain** : Meshy.ai gives 100 credits/month in free tier ( It has an easter egg as well, keep reading ). It works best with images. The model generation itself cost 10-30 credits, which means I had to save them for models. So, I had to visit *duck.ai* which was better anyways, I could go on experimenting with the concept before actual model. Here is what I came up with -

**The Second Pain** : I didn't researched enough before committing to this project. I figured it will require Roblox Studio to add my own accessory to Account. So I had to give up, and thought I'll just create the models and save them for later.

**The Final Pain** : I felt that due to credit system, Meshy.ai will allow downloadable models *with textures* and it did ***but*** only in **Meshy 6 Lite** which did not even support textures. Now, tbh I'm disappointed cause they did not mention this in the docs, but overall Meshy.ai is helpful. It just didn't match my requirements.

I created three models from **Meshy 6 Lite** and tbh They weren't bad if you know how to texture them. The Model worked awesome for simpler models. I used three images to create three different models. The first image is one shown above, the rest are -
